# 小CMO

本地可运行的态势推演前端：在三维地球上摆放友军 / 敌对单位，下达机动、攻击、雷达指令，并用仿真时钟推进交战。没有后端，单位预置在客户端，适合演示与复盘。

页面只有两个：

| 路由        | 页面     | 做什么                           |
| ----------- | -------- | -------------------------------- |
| `/#/`       | 推演态势 | 实时指挥与交战                   |
| `/#/replay` | 复盘回放 | 按时间轴重放本次交战或预编排剧本 |

从态势页右下角进入回放；回放右上角关闭后回到态势。态势页会尽量保持现场（时钟暂停），避免一进回放推演就被卸掉。

---

## 推演态势

### 地图与编成

- 哥伦布视图（2.5D）海区，本地切片底图；标有三亚、青岛、大连，以及敌对集结海区。
- 友军 14 个单位、敌对 8 个单位，类型含舰船、飞机、无人机、地面装甲。
- 阵营配色固定：友军青、敌对橙。
- 左侧单位列表可定位友军、展开指令菜单；敌对条目只作侦察标记，不能从列表里直接点选指挥。
- 点选友军后可看单位信息：生命、速度、攻击/视野/雷达范围等。未发现的敌对会显示为未知。

### 指挥指令

对友军可下达：

- **移动**：点地图选目标点，沿大地线按仿真时间匀速机动，画出青色航迹与虚线终点。
- **停止**：中断当前机动。
- **攻击**：进入锁定，鼠标靠近可见敌对会吸附，左键确认；进入射程后自动开火。
- **雷达扫描**：单位上展开扫描圈与旋转指针，持续约 3 个仿真秒。

地图右键菜单与列表指令走同一套逻辑。锁定与移动均可 ESC 取消。已被击毁的单位不能再操作。

### 交战规则

- 命中按攻击力扣血；生命到 0 时单位失能、从地图消失，并播放爆炸与冲击波。
- 锁定后画出攻击箭头线；任一方被摧毁则拆除相关锁定。
- 友军全部被歼 → 失败；敌对全部被歼 → 胜利。可重新开始本局。

### 侦察与环境

- 敌对默认不在友军视野里；进入友军视野圈后才显示，并改用可识别名称。
- 顶部控制条：仿真开始/当前时间、倍速（最高 6000x）、风场开关、天气（晴/雾/雨/雷/雷雨/雪/多云）、辐射场。
- 风场是覆盖西太平洋的流线粒子，按风速上色；极高倍速下会跳过绘制以免拖死画面。

### 事件记录

左下角事件日志按仿真秒记录机动、锁定、命中、击毁、扫描、天气等。这些记录会带上路径和位置，供复盘页还原轨迹与特效。

## 复盘回放

左侧是按进度展开的事件列表（可筛友军 / 敌对），中间是独立的态势图，底部是播放条。

- 若本局已经打过（有机动、攻击、击毁、扫描或锁定），回放用**本次实战事件**；否则用**预编排 120 秒剧本**（最终友军胜利）。
- 播放 / 暂停 / 重置、进度拖拽、0.5x～4x 倍速。
- 地图上会按时间插值单位位置，并重放：机动轨迹、攻击线、雷达扫掠、击毁爆炸。被击毁单位在击毁时刻起隐藏。
- 顶部统计：双方剩余单位、攻击次数、当前时刻。

### 镜头

- **自动镜头**（默认）：事件切换时把画面平移到相关单位，机动过程中镜头跟随该单位。默认切镜高度约 380 km，能看到周围编成，而不是贴着海面。
- 切单位时**只平移、不改缩放**。滚轮缩放始终可用，后续切镜会沿用你调过的高度。
- **自由镜头**：不再跟事件切镜，可自行平移、旋转、缩放观察全局。

## 运行

需要 Node.js 16+、npm 8+。

```bash
npm install
npm run dev
```

开发地址默认 `http://localhost:8070/`（哈希路由）。生产构建：

```bash
npm run build
```

本仓库是纯前端演示：单位、剧本、风场都在客户端生成，不依赖业务 API。底图走本地 `/tiles/{z}/{x}/{y}.png`。
