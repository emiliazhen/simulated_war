
## 快速开始

### 先决条件

- **Node.js**: 版本 16.0.0。
- **npm**: 版本 8.0.0 或更高。

### 安装
1. 克隆仓库：

```bash
cd pig-ui
```

2. 安装依赖：

```bash
npm install  --registry=https://registry.npmmirror.com
```

### 开发

```bash
npm run dev
```

### 构建

为生产环境构建项目：
```bash
npm run build
```

为 Docker 构建项目：
```bash
npm run build:docker
```

## 浏览器支持

- 现代浏览器的最后两个版本。
- 不支持 IE 11 及更低版本。
